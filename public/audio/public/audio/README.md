# Audio files

Place your comparison files in this folder using these exact filenames:

- `project-01-before.mp3` and `project-01-after.mp3`
- `project-02-before.mp3` and `project-02-after.mp3`
- `project-03-before.mp3` and `project-03-after.mp3`
